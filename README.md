# combine-Osint-tools
ini adalah script osint untuk mencari status email, hubungan email dengan sosmed, jejak nomor telfon, dan email terkait ke website.
pastikan dalam ranah legal untuk melakukan osint kepada target dan segala perbuatan yang dilakukan tanpa izin maka 
masuk dalam undang undang ITE yang berakibat tindak kriminal.
saya selaku pembuat script tidak pernah bertanggung jawab atas semua kejahatan yang di salah gunakan karna memakai script saya.
script ini bertujuan untuk mempermudah osint dan di lakukan hanya ranah dengan izin saja.
silahkan untuk menginstal bisa buka di folder "tata cara instal osint_triad.py"
